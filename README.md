# صيّاد الفرص — مساعد Gemini

واجهة عربية خاصة بالمالك، مبنية على Vercel Functions وGoogle Gemini API.

## الموجود
- واجهة عربية RTL مناسبة للهاتف.
- دخول برمز مالك محفوظ في متغيرات البيئة وجلسة HttpOnly موقعة.
- محادثة Gemini من الخادم دون كشف المفتاح للمتصفح.
- Google Search grounding للمساعدة في البحث عن معلومات حديثة.
- نقطة فحص صحة وجدولة تجريبية يومية.

## الإعداد
1. اربط المستودع بمشروع Vercel بعد التأكد من المشروع المستهدف.
2. أضف في Vercel Environment Variables: GEMINI_API_KEY وOWNER_ACCESS_CODE وSESSION_SECRET (عشوائي بطول 32 حرفاً على الأقل). اختياري: GEMINI_MODEL.
3. انشر المشروع ثم افتح الموقع وسجّل الدخول.
4. اختبر /api/health بعد الدخول.

## حدود مهمة
هذه نسخة تأسيسية وليست وكيلاً مستقلاً مكتملاً. لا توجد حالياً قاعدة بيانات دائمة للمحادثات أو المهام، ولا جامع فرص يعمل بالخلفية، ولا إشعارات، ولا تقديم آلي. مهمة Cron الحالية فحص تجريبي فقط وليست تشغيل 24/7. وظائف Vercel القصيرة لا تضمن عاملاً دائماً. التشغيل المستمر يحتاج Cloud Run مع Cloud Scheduler/Tasks وقاعدة Firestore ومراقبة وحدود تكلفة. أي إرسال طلب أو إجراء خارجي يجب أن يتطلب موافقة المالك ويحترم شروط المواقع.
