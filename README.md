# صيّاد الفرص — مساعد Gemini للمالك

واجهة عربية خاصة بالمالك، مبنية على Vercel Functions وGoogle Gemini API، وتتيح:
- تسجيل دخول آمن للمالك برمز خاص
- تحليل المهارات والهدف
- توليد فرص دخل قابلة للتنفيذ
- عرض النتائج في واجهة عربية RTL جاهزة للموبايل
- فحص صحة الخدمة تلقائياً عبر cron

## المكونات
- `public/index.html`: واجهة المستخدم كاملة
- `api/auth.js`: تسجيل الدخول والتحقق من مالك الموقع
- `api/chat.js`: محادثة نصية عامة مع Gemini
- `api/ideas.js`: مولد الفرص والدخل من المهارات والهدف
- `api/health.js`: فحص صحة الخدمة
- `vercel.json`: إعدادات النشر والـ cron

## المتغيرات المطلوبة
في Vercel → Project → Settings → Environment Variables أضف:
- `GEMINI_API_KEY`: مفتاح Google AI Studio / Gemini
- `OWNER_ACCESS_CODE`: رمز الدخول الخاص بالمالك
- `SESSION_SECRET`: سلسلة عشوائية لا تقل عن 32 حرفاً
- `GEMINI_MODEL`: اختياري، مثل `gemini-2.5-flash`

## التشغيل محلياً
```bash
npm install
npm run dev
```
ثم افتح الرابط المحلي الذي يعطاه Vercel Dev.

## النشر على Vercel
1. ارفع المشروع إلى GitHub.
2. أنشئ مشروع جديد في Vercel وربط نفس الريبو.
3. أضف المتغيرات المطلوبة في إعدادات المشروع.
4. اضغط Deploy.
5. بعد النشر، افتح الموقع وسجل الدخول باستخدام `OWNER_ACCESS_CODE`.

## استخدام الواجهة
1. أدخل رمز المالك.
2. اكتب المهارات التي تملكها.
3. اكتب هدفك.
4. اضغط زر إنشاء فرص الدخل.
5. سيُرجع النظام 5 فرص مرتبة من الأسرع دخلاً إلى الأبطأ مع تفاصيل التنفيذ والمخاطر.

## ملاحظات مهمة
- هذه النسخة جاهزة للاستخدام الوظيفي داخل Vercel.
- لا توجد قاعدة بيانات دائمة في هذا الإصدار، لذا البيانات تُدار داخل كل طلب فقط.
- لا تستخدم هذا النظام دون HTTPS، خاصة في الإنتاج.
- يوصى بتحديث `SESSION_SECRET` بشكل دوري إذا تم نشر المشروع في بيئة حقيقية.
